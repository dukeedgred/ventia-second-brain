Transport analytics One-slide summary: what Asset Vision lacks versus what SRAPC adds

Asset Vision has actual cost fields, but raw job-level cost is uneven. SRAPC adds the missing drivers.

Validation uses raw Asset Vision source actuals from timesheetitem.Cost; plannedresourceitem is excluded because it is planned, not historical actual. SRAPC adds the traffic, incident/KPI, workflow, rework and civil-risk fields needed to explain cost where actual cost is populated.

Asset Vision as-is

The validated gaps are different types of issues.

Cost data quality issue Actual source cost checked: timesheetitem.Cost only. Gen7 is partly populated; RMS is mostly missing / $1-like; VicRoads is mostly zero / missing; VSM has no populated timesheet cost.
Analytics-readiness issue Traffic, incident/KPI and follow-up values are not exposed as a clean job-level driver set; they need formfield pivots and workflow/comment joins.
Data availability issue Civil-risk fields such as functional failure, risk rating, P-F interval and immediate response time are not found as raw Asset Vision physical columns.
Cost lineage issue Power BI cost still needs lineage back to the Asset Vision source / joins. This slide should not treat planned resource cost as historical actual.
