# Contractor KPI / Reporting Areas And Asset Vision Buildability

Evidence basis: inferred from Databricks schema names, table names, view names, and broad table domains. This is not an official contractual KPI schedule. The purpose of this page is to start from the **KPI/reporting areas each contractor appears to report**, then assess whether each area can be rebuilt from Asset Vision source tables.

## Buildability Legend

| Buildability | Meaning |
|---|---|
| Yes | The metric can be built mainly from Asset Vision source tables. |
| Partial | The core count or denominator can be built from Asset Vision, but the official KPI needs external reference tables, special business rules, historical snapshots, or non-Asset-Vision data. |
| No | The KPI/reporting area depends on non-Asset-Vision tables or source systems. |
